# 墨流 · Moflow Studio

面向 Windows 的本地素材与 AI 创作工作台。将抖音参考搜索、素材管理、DeepSeek 对话、提示词逆向、RunningHub 收藏应用与创作任务放在同一个黑白灰桌面界面中。

**本仓库提供完整业务源码，不含个人 API Key、Cookie、浏览器资料、数据库、素材或编译成品。** 需要自行准备开发环境、账号和模型服务。第三方网站适配可能随页面或接口变化失效。

## 功能与作用

| 页面 | 作用 |
|---|---|
| 工作台 | 创建入口、运行项目、待处理事项、最近产物、活动记录及 ASCII 月海 |
| AI 助手 | DeepSeek/兼容模型聊天、附件、可见工具步骤、历史和制作笔记 |
| 创作中心 | 创建卡片、草稿、项目阶段、产物、灵感及自动化规则 |
| 发现 | 抖音作品/用户搜索、推荐、作者主页、评论、在线播放及下载 |
| 资料库 | 图片/视频分开筛选，抖音/ComfyUI/RunningHub来源分类，预览、目录索引与定位文件 |
| AI 应用 | 同步 RunningHub 收藏，在桌面内嵌官网打开、上传、调整参数与手动运行 |
| 下载 | 队列、暂停、恢复、取消、失败重试、校验与去重 |
| 收件箱 | 网页适配的会话/通知、回复草稿与受规则约束的账号动作 |
| 统计 | 实际下载活动热力图和记录，历史导入不伪造下载日期 |
| 插件 | 内置素材工具箱、笔记及可选 MCP stdio 扩展；不是 DSH/Cordis 原生插件运行时 |
| 设置 | 账号、模型、加密凭据、目录、空间额度、预算和 MCP |

没有直播录制功能，不依赖 Better Douyin 程序运行。索引原素材不移动文件。

## 快速开始

- 本机已有成品：双击“墨流 Studio”；关闭窗口进入托盘，彻底退出使用托盘 Exit。便携目录中的服务和 `_internal` 必须完整保留。
- 从本仓库部署：先按 [安装与开发](docs/安装与开发.md)启动，再按 [使用手册](docs/使用手册.md)设置目录、账号和模型。
- 只收集素材：配置目录并登录抖音即可使用，不要求配置 AI。
- 手动创作：下载参考 → 资料库选图 → AI 应用打开收藏 → 官网上传与运行。
- 自动创作：创作中心保存草稿，补齐参考、模型、RunningHub API、字段映射及独立预算后启动；缺配置或无法确定费用时暂停。

## 搜索与推荐

搜索优先使用本账号短期缓存，可手动重新搜索。推荐使用三个女性单人舞蹈查询分批召回，筛选近七天、至少千赞的标题匹配作品；按作品 ID 去重，每位已知作者最多两条，最多显示18条。

支持综合、最新、点赞排序。综合以点赞、新鲜度、时间归一化点赞进行排名融合，是墨流自定规则，不是抖音或 Pamba 的原始算法。**标题和作者资料不能证明成年、单人、平视或不挡脸，卡片显示画面待确认。** 视频分析抽五帧，也不等于逐帧检查。

## 模型与费用

文本/视觉分别配置，支持 Ollama、DeepSeek 官方适配和兼容接口。以服务商当前模型列表为准，不自动购买服务或下载模型。RunningHub 网页登录与 API Key 是两套凭据。

自动生产包含调研、参考分析、服装提示词、角色图、可选换衣、动作迁移、检查及 MP4 归档。用户配置预算并启动后才进入自动提交；各平台费用分单位记录，费用上限不明、回执丢失或结果不明时暂停核对，不盲目再次生成。

**源码与无付费提交测试已完成，真实收费生成闭环尚未完成，不能视为保证出片。** 网站与账号功能的实测边界见测试报告。

## 源码结构

```text
src/             React 19 + TypeScript 页面
src-tauri/       Tauri 2 / Rust 桌面、托盘、文件选择、WebView2
backend/         FastAPI、SQLite、浏览器、下载、聊天、工作流与预算
backend/vendor/  保留来源的第三方辅助源码
scripts/         构建、检查与现场验收
 tests/          后端回归测试
vendor/          第三方许可证及原始组件记录
docs/            使用与安装文档
```

后端默认 `http://127.0.0.1:7861`，开发前端 `http://127.0.0.1:5178`。网页模式没有桌面原生文件定位、内嵌网站和上传桥接能力。MCP 复用业务服务和权限规则，仅供本机使用。

运行目录由 `MOFLOW_DATA` 指定；原默认目录和构建脚本带有开发机 D 盘布局，换电脑应调整。密钥通过 Windows DPAPI 保存在本机，不随源码迁移。详见 [SECURITY.md](SECURITY.md)。
