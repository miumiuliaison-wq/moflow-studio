# 使用手册

## 首次配置

1. 设置素材根目录、ComfyUI 索引目录和图片/视频参考目录。默认开发机路径不一定存在，请选择自己的实际目录。
2. 设置空间额度和最少空闲空间。默认新采集额度8GB、至少保留10GB空闲，空间不足暂停相关步骤。不要把运行数据存进源码目录。
3. 点击抖音登录，在程序专用 Chrome 完成登录和验证。登录过不代表所有请求都无需验证。
4. 需要 AI 时配置文本和视觉模型，界面保存自己的密钥并测试连接。
5. RunningHub 使用独立登录，刷新“个人中心 → 我的收藏 → AI应用”；网页登录不能替代 API Key。

## 搜索、推荐与下载

发现页选择作品或用户，输入关键词搜索。结果显示实时或本机缓存来源，点击“重新搜索抖音”强制更新。推荐分三路查询，先显示已取得候选，后续继续补充；可切换综合、最新和点赞排序，换一批可能仍返回相同作品。人数与遮挡仍需观看确认。

点击作品预览、查看作者或加入下载；可勾选批量下载。下载页查看进度、暂停、恢复或重试。登录/空间问题解决后续跑已有任务，不重复新建。

## 资料库与图片逆向

本地素材按视频/图片、来源两层筛选。刷新素材增量扫描，导入目录只建索引，不移动原文件。失效文件保留记录。定位文件在资源管理器选中；打开文件用于预览；打开本地文件夹列出对应目录。切换筛选会清空勾选。

选择图片分析或逆向，或在AI助手附加素材说明要求。逆向输出中文正负提示词到同一 Markdown，负向用“无……”形式。默认忠实描述可见画面；全身平视改写会标记补充内容。视频抽帧分析不等于逐帧检查。

## AI 对话与插件

AI助手保留会话、附件、工具步骤和结果；项目详情可携带只读项目上下文，不改变生成或账号权限。模型缺配置时先补配置。

插件页管理内置素材工具箱、笔记及 MCP stdio 扩展。外部插件可以启动本机程序，应先阅读配置，只安装信任的程序。DSH/Cordis 原生插件包不能直接运行。

## RunningHub 收藏应用

进入AI应用、刷新收藏、点击卡片，在桌面内打开官网。上传、参数、手动运行遵从官网控件；费用以网页实际显示为准。图片/视频上传选择器从设置的参考目录开始，可换目录；取消不清除原素材。

手动下载的图片/视频经检查归档并加入资料库。ZIP保留原件，只安全提取支持媒体，未知附件不执行。网站控件变更可能需要维护。网页开发模式不具备桌面内嵌和上传桥接。

## 草稿和自动生产

创作中心每张卡片可独立保存、复制、删除。参考从发现页“用于创作”、资料库、链接或本地上传进入。填写人物/服装要求、时长、账号和 DeepSeek/RunningHub 独立预算。

保存草稿不生成；批量启动只提交齐备卡片。自动生产另需 RunningHub API 权限、实际应用字段映射与可靠费用依据。缺配置、预算不足或费用不明暂停。项目页查看阶段、产物、失败原因及恢复操作。回执不明确先查原任务，重新下载不要重新生成。

## 收件箱、规则、MCP 与退出

规则默认关闭；启用前指定账号、对象、动作、条件、频率与数量上限。发送待核对时先查平台回执，避免重复消息。界面不能识别的网站能力会报错，不展示模拟结果。

MCP地址和令牌在设置中获取，仅供本机客户端；请求头用 `Authorization: Bearer <本机令牌>`。不要分享令牌，账号动作仍受规则约束。

关闭窗口进入托盘，Exit彻底退出。“暂停全部自动化”停止新自动步骤，已经提交云端的任务可能仍继续执行和计费，暂停不等于停止云端计费。
